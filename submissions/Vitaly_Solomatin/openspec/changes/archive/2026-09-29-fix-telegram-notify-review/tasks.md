## 1. Клієнт Bot API: повтори і кількість спроб

- [x] 1.1 `TelegramError.attempts` і передача номера спроби в кожне місце, де клієнт кидає помилку
      (`design.md`, рішення 2); перевірка: у `tests/test_notify_parts.py` тести стверджують
      `e.attempts == 1` для 403 і `e.attempts == 3` для постійного `ConnectError`.
- [x] 1.2 Ознака `idempotent` у `_call`: `send` повторює лише `ConnectError`, `ConnectTimeout`,
      `PoolTimeout` і 429, а `get_updates` зберігає поточні повтори (`design.md`, рішення 1);
      перевірка: `test_retries_502_then_ok` замінено тестом «502 — один запит, `TelegramError` з
      `attempts == 1`»; нові тести: `httpx.ReadTimeout` і `httpx.RemoteProtocolError` дають рівно
      один запит; `ConnectError`, потім 200 дає `send() == 2`; `getUpdates` на 502, потім 200
      робить два запити. Наявні тести на 429, 403, `redact` і `getUpdates` 409 зелені без змін.
