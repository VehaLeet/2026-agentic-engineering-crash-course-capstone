- [x] 4.4 Перевірка правильних кредів: тест на `GET /status` стверджує 200.
- [x] 4.5 `GET /health` поза автентифікацією; перевірка: тест без кредів стверджує 200 і тіло

- [x] 4.6 Кожен маршрут, крім `/health`, захищений; перевірка: тест обходить `app.routes` і для

- [x] 5.4 Успішний фоновий збір; перевірка: після `wait_all` `GET /runs/{id}` повертає

- [x] 5.5 Збій джерела у фоні; перевірка: після `wait_all` `GET /runs/{id}` повертає `error` з

- [x] 5.7 Опорна дата у фоновому зборі — Kyiv; перевірка: тест із підставленим `now`
