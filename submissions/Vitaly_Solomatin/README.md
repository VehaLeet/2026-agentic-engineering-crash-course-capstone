# OREE DAM Monitor

Внутрішній сервіс, що сам відстежує результати торгів ринку «на добу наперед» (РДН) ОРЕЕ:
завантажує офіційні дані, зберігає їх, показує графік і таблицю цін і надсилає сповіщення в
Telegram, коли з'являються нові чи перераховані доби. Опис продукту — `docs/brief.md`.

## Швидкий старт

Потрібні лише **Docker** (з Compose) і **make**.

```sh
make up
```

Відкрийте http://127.0.0.1:8080. Під час першого запуску `make up` створює `.env` з `.env.example`,
застосовує міграції і одразу робить перший збір даних з ОРЕЕ.

Графік спершу покаже лише поточний квартал. Щоб завантажити всю історію з 01.07.2019
(кілька хвилин):

```sh
make backfill
```

## Команди

| Команда | Що робить |
|---|---|
| `make up` | Зібрати й запустити сервіс, дочекатися готовності |
| `make down` | Зупинити сервіс; дані бази зберігаються |
| `make logs` | Журнали всіх сервісів у реальному часі |
| `make ps` | Стан сервісів |
| `make backfill` | Завантажити історію РДН з 01.07.2019 |
| `make clean` | Видалити контейнери, **базу даних** і зібрані образи (з підтвердженням; `.env` лишається) |

Без підтвердження: `make clean FORCE=1`.

## Сповіщення в Telegram (необов'язково)

1. Створіть бота в [@BotFather](https://t.me/BotFather) і впишіть токен у `.env`:
   `TELEGRAM_BOT_TOKEN=...`
2. Перезапустіть: `make down && make up`.
3. Напишіть боту `/start`, відкрийте вкладку «Налаштування» → «Знайти чати» → «Додати».
   Кнопка «Надіслати тест» перевіряє доставку.

## Доступ і безпека

Сервіс не має автентифікації, тому доступний **лише з цієї машини**: усі порти опубліковано на
`127.0.0.1` (UI — 8080, API — 8000, Postgres — 5432). Не змінюйте це, щоб відкрити сервіс у мережу:
для цього спершу потрібні автентифікація і HTTPS (див. «Борги» в `docs/roadmap.md`).

Якщо порт уже зайнятий, змініть ліву частину відповідного `127.0.0.1:<порт>:...` у
`docker-compose.yml`.

## Розробка

База для розробки — той самий сервіс Postgres: `docker compose up -d postgres`. Далі API —
`cd backend && uv run python -m app.api`, UI — `cd frontend && npm run dev`, тести — `uv run pytest`
і `npm test`. Контейнерний стек і dev-запуск використовують **одну й ту саму базу** (том
`postgres_data`), тож `make clean` видалить і дані, з якими ви працювали локально.

Порядок і стан робіт — `docs/roadmap.md`; специфікації — `openspec/specs/`.
